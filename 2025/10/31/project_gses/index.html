广厦二手 小程序 全栈项目

上次更新: 2025-10-31 14:43:55

项目概述

广厦二手交易小程序，实现跨校区商品发布与撮合交易等，服务学生群体，促进资源循环利用。
项目展示在最下方

技术架构

前端技术栈

  • 框架: Uniapp
  • 状态管理: Pinia
  • 开发语言: TypeScript
  • CSS原子化: UnoCSS
  • CSS预处理: SCSS
  • UI框架: uView plus
  • 实时通信: Socket.IO
  • 代码规范: ESLint + Prettier

后端技术栈

  • 框架: NestJS
  • 数据库: MySQL + Prisma ORM
  • 开发语言: TypeScript
  • 实时通信: Socket.IO(兼容weapp)
  • 对象存储: 微信云COS
  • 日志管理: Nestjs-Pino
  • API文档: Swagger
  • 端到端测试:Jest + Supertest

数据库设计

项目采用 MySQL 关系型数据库，通过 Prisma ORM 进行数据建模和操作。主要数据表包括：

  1. 用户表 (User): 存储用户基本信息、微信 openid、联系方式等
  2. 商品表 (Product): 存储商品信息、价格、描述、分类等
  3. 商品图片表 (ProductImage): 存储商品图片信息
  4. 会话表 (Conversation): 存储买卖双方的沟通会话
  5. 消息表 (Message): 存储具体的聊天消息
  6. 通知公告表 (Notice): 存储系统通知和公告
  7. 统计数据表: 包括商品浏览量、上下架量等统计信息
  8. Banner管理表: 用于管理系统首页轮播图

功能模块

用户模块

  • 微信授权登录（云开发鉴权、会话控制）
  • 个人资料管理
  • 联系方式设置（微信、手机号、可见性）
  • 校区选择

商品模块

  • 商品发布（标题、价格、描述、图片、分类、支持二次编辑重新发布）
  • 商品呈现（智能排序、个性化排序、用户行为定时更新、运营行为即时更新）
  • 商品搜索（关键词、链接解析）
  • 图片分场景视觉策略（瀑布流卡片、自适应卡片、标准卡片）
  • 分类筛选（资料、服饰、食物、生活用品、电子产品、运动器材等）
  • 状态管理（上架、下架、删除）

聊天模块

  • 聊天消息
  • 功能面板（发送图片、交换联系）
  • 未读消息反馈
  • 会话列表管理

运营模块

  • 数据统计（数据记录、动态变化、导出CSV）
  • 人工加权（指定商品排序优先级变化）
  • 公告管理（公告发布、公告历史查询与编辑）
  • Banner管理（轮播停留时长、跳转链接、默认banner、关闭Banner）

部署与运维

  • 前端上传微信小程序，版本控制
  • 后端Docker容器化部署于微信云托管，流水线推送
  • 存储服务采用微信云MYSQL与对象存储
  • 云托管后台、小程序助手、We分析 实时监控项目及数据统计分析
